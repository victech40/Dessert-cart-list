# Dessert Cart List

A responsive web application for browsing and managing a list of desserts. Users can view dessert details, add items to their cart, and proceed to checkout. The application is designed to work seamlessly across various devices, including desktops, tablets, and mobile phones.

## Features

- **Responsive Design**: Optimized for all screen sizes using modern CSS techniques.
- **Interactive Cart**: Add, remove, and update quantities of desserts in the cart.
- **Dynamic Content**: Displays dessert details dynamically from a data source.
- **Modern UI**: Clean and visually appealing design.

## Technologies Used

- **HTML5**: For structuring the content.
- **CSS3**: For styling and responsive design.
- **JavaScript**: For interactivity and dynamic content management.

## Folder Structure

```
product-list-with-cart-main/
├── assets/
│   ├── fonts/          # Font files used in the project
│   ├── images/         # Images for desserts and icons
│   └── design/         # Design mockups and active states
├── data.json           # Data source for desserts
├── index.css           # Stylesheet for the application
├── index.html          # Main HTML file
├── preview.jpg         # Preview image of the application
```

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/victech40/Dessert-cart-list.git
   ```

2. Navigate to the project directory:
   ```bash
   cd product-list-with-cart-main
   ```

3. Open `index.html` in your browser to view the application.
